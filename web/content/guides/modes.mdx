# Ask, Agent, and Plan Modes

ANAS CLI provides three interaction modes: **Ask**, **Agent**, and **Plan**. Each mode represents a different way to approach coding tasks.

## Select a mode

Use the `--mode` option when starting an interactive chat:

```bash
npm run dev -- chat --mode ask
```

```bash
npm run dev -- chat --mode agent
```

```bash
npm run dev -- chat --mode plan
```

The default mode is `agent`.

## Ask mode

Use Ask mode to explore your codebase, understand existing code, and discuss implementation ideas.

**Example prompts**

- Explain how this function works.
- What does this error mean?
- How could this module be simplified?

Ask mode is best suited to investigation and understanding before making changes.

## Agent mode

Use Agent mode when you want assistance carrying out a coding task.

**Example prompts**

- Help me implement input validation.
- Find where this function is called.
- Help me fix this failing test.

Review generated changes and command results before relying on them.

## Plan mode

Use Plan mode to explore an implementation approach before proceeding with a coding task.

**Example prompts**

- Outline the steps to add authentication.
- Identify which modules need to change for this feature.
- Propose an approach for handling API errors.

Planning helps you understand the scope of a change before committing to an implementation.

## Implementation notes

Mode names are accepted by the CLI, but their specific behavior depends on the interactive chat implementation.

The one-shot `talk` command sends a prompt directly to the selected provider and does not currently accept a `--mode` option.
