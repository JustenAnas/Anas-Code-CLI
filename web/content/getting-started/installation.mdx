# Installation

ANAS CLI currently runs from source code. Follow these steps to install dependencies, configure your environment, and launch the CLI.

## Prerequisites

Before you begin, make sure you have:

- [Node.js](https://nodejs.org/) version 18 or higher.
- npm installed.
- The ANAS CLI repository cloned to your machine.

## 1. Open the project

Open your terminal in the root directory of the ANAS CLI repository.

All commands below should run from this directory, where the root `package.json` is located.

## 2. Install dependencies

Install the project dependencies:

```bash
npm install
```

## 3. Configure environment variables

ANAS CLI uses a root-level `.env` file for environment configuration.

Add the API key for the provider you intend to use:

| Provider   | Environment variable |
| ---------- | -------------------- |
| Claude     | `ANTHROPIC_API_KEY`  |
| OpenAI     | `OPENAI_API_KEY`     |
| OpenRouter | `OPENROUTER_API_KEY` |
| Gemini     | `GEMINI_API_KEY`     |
| Groq       | `GROQ_API_KEY`       |

For example, to configure OpenAI:

```bash
OPENAI_API_KEY=your_openai_api_key
```

Replace the placeholder with your actual API key. You do not need to configure every provider.

Keep your API keys private. Never commit your `.env` file to Git or share your credentials publicly.

## 4. Check your environment

Run the environment check:

```bash
npm run dev -- doctor
```

This checks that Node.js is version 18 or higher and reports whether API keys are configured. It does not guarantee that the keys are valid or have sufficient credits.

## 5. Start in development mode

Run the CLI directly from its TypeScript source:

```bash
npm run dev -- --help
```

To launch the guided setup:

```bash
npm run dev -- wakeup
```

This command runs `src/index.ts` through `tsx`, so you can use the CLI without compiling it first.

## 6. Build for production

Compile the TypeScript project:

```bash
npm run build
```

After a successful build, start the compiled application:

```bash
npm start
```

The production command runs `dist/index.js`. Make sure your TypeScript configuration emits the entry point to that location before using it.
