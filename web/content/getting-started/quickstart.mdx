# Quickstart

Get your first ANAS CLI session running. You can launch the guided setup, start a chat directly, choose an operating mode, or send a one-shot prompt.

## 1. Check your setup

Run the doctor command to check your environment:

```bash
npm run dev -- doctor
```

The doctor command checks your Node.js version and the required Anthropic API key.

## 2. Start the guided experience

Run:

```bash
npm run dev -- wakeup
```

The guided startup displays the banner, checks prerequisites, and lets you select a provider and mode before chatting.

## 3. Start a chat

Launch an interactive session in the default mode:

```bash
npm run dev -- chat
```

You can also choose a mode explicitly.

### Ask mode

Ask questions and explore your codebase.

```bash
npm run dev -- chat --mode ask
```

### Plan mode

Plan an approach before making changes.

```bash
npm run dev -- chat --mode plan
```

### Agent mode

Work interactively with the coding agent.

```bash
npm run dev -- chat --mode agent
```

## 4. Send a one-shot prompt

Use `talk` to submit a single prompt:

```bash
npm run dev -- talk "Explain the structure of this project"
```

This is useful when you want a direct response without starting an interactive chat session.

## 5. Show token usage and cost

Add `--verbose` to supported commands to display additional usage information:

```bash
npm run dev -- chat --verbose
```

```bash
npm run dev -- wakeup --verbose
```

```bash
npm run dev -- talk "Explain this function" --verbose
```

## More commands

| Command | Description |
| --- | --- |
| `banner` | Displays the welcome banner. |
| `hello` | Prints a greeting. |
| `doctor` | Checks whether the environment is ready. |

To see the available CLI commands and options, run:

```bash
npm run dev -- --help
```
