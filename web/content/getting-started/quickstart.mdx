# Quickstart

Get your first ANAS CLI session running. You can check your environment, use guided setup, choose an operating mode, or send a one-shot prompt.

## 1. Check your setup

Run the doctor command:

```bash
npm run dev -- doctor
```

The doctor command checks that Node.js is version 18 or higher and reports whether API keys are configured for Claude, OpenAI, OpenRouter, Gemini, and Groq.

## 2. Start the guided experience

Run:

```bash
npm run dev -- wakeup
```

The guided startup displays the welcome banner, checks the environment, and lets you select a provider and interaction mode.

If you select OpenRouter, ANAS CLI fetches eligible text models that support tool calling and lets you choose one.

Your provider and mode selections are saved in the CLI configuration.

To display token usage and estimated cost, use:

```bash
npm run dev -- wakeup --verbose
```

## 3. Start an interactive chat

Launch a session in the default mode, Agent:

```bash
npm run dev -- chat
```

You can also choose a mode explicitly.

### Ask mode

Explore your codebase and ask questions without making changes.

```bash
npm run dev -- chat --mode ask
```

### Plan mode

Discuss an implementation approach before making changes. Plan mode currently has no tools enabled.

```bash
npm run dev -- chat --mode plan
```

### Agent mode

Work interactively with the coding agent. Tool access is subject to permission checks and safety guardrails.

```bash
npm run dev -- chat --mode agent
```

## 4. Send a one-shot prompt

Use `talk` to submit a single prompt:

```bash
npm run dev -- talk "Explain the structure of this project"
```

This sends a prompt without starting an interactive chat session.

To display token usage and estimated cost:

```bash
npm run dev -- talk "Explain this function" --verbose
```

## 5. Switch modes during a session

While an interactive chat is running, enter one of these slash commands:

```text
/mode ask
/mode agent
/mode plan
```

Use `/help` to see the available slash commands.

Other supported commands include:

| Command    | Description                   |
| ---------- | ----------------------------- |
| `/new`     | Start a new conversation.     |
| `/history` | View conversation history.    |
| `/resume`  | Resume a conversation.        |
| `/exit`    | Exit the interactive session. |

## 6. Sign in to ANAS Cloud

Use the following commands to manage your ANAS Cloud login:

```bash
npm run dev -- login
```

Log out when needed:

```bash
npm run dev -- logout
```

## More commands

| Command  | Description                            |
| -------- | -------------------------------------- |
| `wakeup` | Launch guided setup.                   |
| `chat`   | Start an interactive session.          |
| `talk`   | Send a one-shot prompt.                |
| `doctor` | Check Node.js and configured API keys. |
| `login`  | Log in to ANAS Cloud.                  |
| `logout` | Log out of ANAS Cloud.                 |
| `banner` | Display the welcome banner.            |
| `hello`  | Print a greeting.                      |

To see all available CLI commands and options, run:

```bash
npm run dev -- --help
```
