# Quickstart

Get ANAS CLI running, configure an AI provider, start coding, and explore ANAS Cloud.

## 1. Check your setup

Run the doctor command:

```bash
npm run dev -- doctor
```

The doctor command checks that Node.js is version 18 or higher and reports whether API keys are configured for Claude, OpenAI, OpenRouter, Gemini, and Groq.

It checks whether credentials are configured, not whether they are valid or have sufficient credits.

## 2. Start the guided experience

Run:

```bash
npm run dev -- wakeup
```

The guided startup displays the welcome banner, checks the environment, and lets you select a provider and interaction mode.

ANAS CLI supports:

- OpenAI
- Claude
- OpenRouter
- Gemini
- Groq

If you select OpenRouter, ANAS CLI fetches eligible text models that support tool calling and lets you choose one.

Your provider and mode selections are saved in the CLI configuration.

To display token usage and estimated cost when available:

```bash
npm run dev -- wakeup --verbose
```

## 3. Start an interactive chat

Launch a session in the default mode, Agent:

```bash
npm run dev -- chat
```

You can also choose a mode explicitly.

### Ask mode

Explore your codebase, read files, search code, and ask questions without modifying project files.

```bash
npm run dev -- chat --mode ask
```

Ask mode supports these read-only tools:

- `read_file`
- `search_code`
- `glob`
- `list_dir`

### Plan mode

Discuss an implementation approach before making changes.

```bash
npm run dev -- chat --mode plan
```

Plan mode currently has no registered tools enabled.

### Agent mode

Work interactively with the coding agent.

```bash
npm run dev -- chat --mode agent
```

Agent mode can access all registered tools, subject to permission checks and safety guardrails.

ANAS CLI requests confirmation before terminal commands and file-writing or editing operations.

See [Modes](/docs/guides/modes) and [Tools & Permissions](/docs/reference/tools).

## 4. Send a one-shot prompt

Use `talk` to submit a single prompt:

```bash
npm run dev -- talk "Explain the structure of this project"
```

This sends a prompt without starting an interactive chat session.

To display token usage and estimated cost when supported:

```bash
npm run dev -- talk "Explain this function" --verbose
```

## 5. Switch modes during a session

While an interactive chat is running, enter one of these slash commands:

```text
/mode ask
/mode agent
/mode plan
```

Use `/help` to see the available slash commands.

Other supported commands include:

| Command | Description |
| --- | --- |
| `/new` | Start a new conversation. |
| `/history` | View conversation history. |
| `/resume` | Resume a conversation. |
| `/exit` | Exit the interactive session. |

## 6. Sign in to ANAS Cloud

ANAS Cloud provides account-based services for ANAS CLI.

Start the cloud login flow:

```bash
npm run dev -- login
```

After successful authentication, ANAS CLI saves a cloud access token in its local configuration.

The CLI uses this token when communicating with protected cloud endpoints.

CLI tokens expire after 30 days. Browser sessions and CLI authentication use separate mechanisms.

### Cloud provider keys

ANAS Cloud supports authenticated provider-key management.

The backend allows you to:

- Check whether a provider key exists.
- Save or replace a provider key.
- Delete a saved provider key.

Cloud provider keys are encrypted using AES-256-GCM before database storage.

Each saved key is associated with the authenticated account.

Local provider keys configured through environment variables remain a separate configuration option.

See [AI Providers](/docs/configuration/providers).

## 7. Use Cloud OpenAI

ANAS CLI includes an authenticated cloud OpenAI integration.

The cloud endpoint currently uses `gpt-4o` and supports:

- Standard AI responses
- Streaming responses
- Tool-call responses
- Token usage reporting when available

The backend retrieves the authenticated user's saved OpenAI key and decrypts it server-side when processing a cloud request.

Cloud OpenAI requests are limited to **30 requests per minute per authenticated user**.

If you exceed this limit, the API returns HTTP `429` with a `Retry-After` header.

This limit does not guarantee a maximum API bill.

See [ANAS Cloud](/docs/guides/anas-cloud) and [Security](/docs/guides/security).

## 8. Conversations and memory

ANAS CLI provides commands for managing conversation history:

```text
/new
/history
/resume
```

ANAS Cloud also includes backend endpoints for conversation sessions and messages.

Cloud synchronization should only be considered successful when the relevant operation has completed successfully.

The cloud backend also includes a memory endpoint.

Provider-independent memory is an intended capability, but automatic memory retrieval across all providers should not be assumed to be fully integrated.

Learn more:

- [Sessions](/docs/guides/sessions)
- [Memory](/docs/guides/memory)

## 9. Sign out of ANAS Cloud

When you want to end your locally authenticated cloud session, run:

```bash
npm run dev -- logout
```

You can sign in again using `login`.

| Command | Description |
| --- | --- |
| `wakeup` | Launch guided setup. |
| `chat` | Start an interactive session. |
| `talk` | Send a one-shot prompt. |
| `doctor` | Check Node.js and configured API keys. |
| `login` | Log in to ANAS Cloud. |
| `logout` | Log out of ANAS Cloud. |
| `banner` | Display the welcome banner. |
| `hello` | Print a greeting. |

To see all available CLI commands and options:

```bash
npm run dev -- --help
```

To display the installed CLI version:

```bash
npm run dev -- --version
```
