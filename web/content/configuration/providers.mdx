# AI Providers

ANAS CLI supports five AI providers. Configure the API key for your preferred provider to start using its models.

## Supported providers

| Provider   | Environment variable |
| ---------- | -------------------- |
| Claude     | `ANTHROPIC_API_KEY`  |
| OpenAI     | `OPENAI_API_KEY`     |
| OpenRouter | `OPENROUTER_API_KEY` |
| Gemini     | `GEMINI_API_KEY`     |
| Groq       | `GROQ_API_KEY`       |

## 1. Configure your API key

Create a `.env` file in the project root and add the key for the provider you want to use.

**Claude**

```bash
ANTHROPIC_API_KEY=your_anthropic_api_key
```

**OpenAI**

```bash
OPENAI_API_KEY=your_openai_api_key
```

**OpenRouter**

```bash
OPENROUTER_API_KEY=your_openrouter_api_key
```

**Gemini**

```bash
GEMINI_API_KEY=your_gemini_api_key
```

**Groq**

```bash
GROQ_API_KEY=your_groq_api_key
```

Replace the placeholder with your actual API key. You only need to configure credentials for the provider you intend to use.

**Security reminder:** Never commit your `.env` file to version control or share your API keys publicly.

## 2. Select a provider

Start the guided setup:

```bash
npm run dev -- wakeup
```

ANAS CLI checks the environment, prompts you to select a provider, and validates that provider's API key.

The supported provider identifiers are:

* `claude`
* `openai`
* `openrouter`
* `gemini`
* `groq`

Your provider selection is saved in the CLI configuration.

### Choose an OpenRouter model

When you select OpenRouter through `wakeup`, ANAS CLI fetches available text-only models that support tool calling and lets you choose one.

The model picker displays the model name, ID, and available input/output pricing information. Free models are labelled accordingly.

If no eligible models are found or the model list cannot be loaded, the setup reports an error.

## 3. Check your environment

Run:

```bash
npm run dev -- doctor
```


This command checks that Node.js is version 18 or higher and reports whether an API key is configured for each supported provider.

It checks for configured keys; this does not necessarily verify that every key is valid or has sufficient credits.


## ANAS Cloud API keys

ANAS CLI supports saving an OpenAI API key through its
authenticated cloud backend.

The backend encrypts saved keys using AES-256-GCM
before storing them in the database.

Cloud requests use the key associated with the
authenticated user. The saved key is not returned
to the CLI through the cloud chat endpoint.

The OpenAI cloud chat endpoint also enforces
30 requests per minute per authenticated user.

This limit does not guarantee a maximum API bill.
Monitor your provider usage and billing settings.

See [Security](/docs/guides/security) for details.


## 4. Troubleshoot API key issues

If you encounter a provider or connection error:

1. Confirm that your `.env` file is in the project root.
2. Check that the environment variable matches your selected provider.
3. Verify that the API key is valid and has the required access or credits.
4. For OpenRouter, check that the selected model is available and supports tool calling.
5. Read the error message and check the provider's service status if needed.
