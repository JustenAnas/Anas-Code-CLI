# CLI Commands

ANAS CLI provides commands for interactive coding sessions, one-shot prompts, guided startup, and environment checks.

## `wakeup`

Start the guided setup flow, including provider and mode selection.

```bash
npm run dev -- wakeup
```

Show token usage and cost when supported:

```bash
npm run dev -- wakeup --verbose
```

## `chat`

Start an interactive streaming chat session. The default mode is `agent`.

```bash
npm run dev -- chat
```

Select a mode explicitly:

```bash
npm run dev -- chat --mode ask
npm run dev -- chat --mode plan
npm run dev -- chat --mode agent
```

### Options

| Option              | Description                       |
| ------------------- | --------------------------------- |
| `-m, --mode <mode>` | Select `ask`, `agent`, or `plan`. |
| `-v, --verbose`     | Show token usage and cost.        |

## `talk`

Send a single prompt and stream the response.

```bash
npm run dev -- talk "Explain this project's structure"
```

### Options

| Option          | Description                |
| --------------- | -------------------------- |
| `-v, --verbose` | Show token usage and cost. |

**Provider behavior:** The current implementation defaults to OpenRouter for this command.

## `doctor`

Check the Node.js version and whether the Anthropic API key is configured.

```bash
npm run dev -- doctor
```

The current check requires Node.js 18 or higher.

Note that this command checks `ANTHROPIC_API_KEY` specifically, even if you intend to use another provider.

## `banner`

Display the welcome banner.

```bash
npm run dev -- banner
```

## `hello`

Print a greeting.

```bash
npm run dev -- hello
```

## Help and version

Display available commands and options:

```bash
npm run dev -- --help
```

Display the CLI version:

```bash
npm run dev -- --version
```

The currently documented CLI version is `0.1.0`.
