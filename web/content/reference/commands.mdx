# CLI Commands

ANAS CLI provides commands for interactive coding sessions, one-shot prompts, guided startup, cloud authentication, and environment checks.

## `wakeup`

Start the guided setup flow, including provider and mode selection.

```bash
npm run dev -- wakeup
```

Show token usage and estimated cost when supported:

```bash
npm run dev -- wakeup --verbose
```

The guided flow lets you select a provider and interaction mode.

When OpenRouter is selected, ANAS CLI offers a model picker for supported text models with tool-calling capabilities.

Your provider and mode selections are saved in the CLI configuration.

## `chat`

Start an interactive streaming chat session.

The default mode is `agent`.

```bash
npm run dev -- chat
```

Select a mode explicitly:

```bash
npm run dev -- chat --mode ask
npm run dev -- chat --mode plan
npm run dev -- chat --mode agent
```

### Options

| Option              | Description                                         |
| ------------------- | --------------------------------------------------- |
| `-m, --mode <mode>` | Select `ask`, `agent`, or `plan`.                   |
| `-v, --verbose`     | Show token usage and estimated cost when supported. |

### Interaction modes

**Ask mode**

Read-only code exploration using `read_file`, `search_code`, `glob`, and `list_dir`.

**Agent mode**

Full coding-agent workflow with access to registered tools, subject to permissions and safety guardrails.

**Plan mode**

Discuss implementation approaches without invoking registered tools.

See [Ask, Agent, and Plan Modes](/docs/guides/modes).

## `talk`

Send a single prompt and stream the response.

```bash
npm run dev -- talk "Explain this project's structure"
```

### Options

| Option          | Description                                         |
| --------------- | --------------------------------------------------- |
| `-v, --verbose` | Show token usage and estimated cost when supported. |

This command runs a one-shot query rather than starting an interactive chat session.

Unlike `chat`, the `talk` command does not currently accept a `--mode` option.

## `doctor`

Check your Node.js version and whether supported provider API keys are configured.

```bash
npm run dev -- doctor
```

The command checks whether Node.js 18 or higher is installed and reports the configuration status of these providers:

| Provider   | Environment variable |
| ---------- | -------------------- |
| Claude     | `ANTHROPIC_API_KEY`  |
| OpenAI     | `OPENAI_API_KEY`     |
| OpenRouter | `OPENROUTER_API_KEY` |
| Gemini     | `GEMINI_API_KEY`     |
| Groq       | `GROQ_API_KEY`       |

The command checks whether keys are configured. It does not guarantee that a key is valid or that the provider account has available credits.

## `login`

Start the ANAS Cloud authentication flow.

```bash
npm run dev -- login
```

After successful authentication, ANAS CLI stores a cloud access token in its local configuration.

The token is used to authenticate requests to protected ANAS Cloud endpoints.

### Cloud authentication

ANAS Cloud uses bearer tokens for CLI authentication.

- CLI access tokens expire after 30 days.
- The backend stores SHA-256 hashes of CLI tokens rather than plaintext tokens.
- Browser sessions use a separate authentication mechanism.
- Protected cloud endpoints identify the authenticated user from the supplied token.

Cloud authentication enables access to supported account-based services, including provider-key management and cloud AI requests.

See [ANAS Cloud](/docs/guides/anas-cloud).

## `logout`

Log out of the ANAS Cloud session.

```bash
npm run dev -- logout
```

This clears the locally stored cloud authentication state.

A local logout should not be confused with guaranteed server-side token revocation unless that operation is performed by the implementation.

To authenticate again, run `login`.

## Cloud Provider Keys

ANAS Cloud supports authenticated provider-key management.

Available backend operations include:

| Operation | Description                                |
| --------- | ------------------------------------------ |
| Check     | Determine whether a provider key is saved. |
| Save      | Store or replace a provider key.           |
| Delete    | Remove a saved provider key.               |

Saved provider keys are encrypted using AES-256-GCM before database storage.

Provider-key records are scoped to the authenticated user.

The cloud OpenAI endpoint retrieves the authenticated user's saved OpenAI key server-side. The key is not returned to the CLI as part of a cloud chat response.

These operations are backend capabilities and should not be confused with separate CLI commands.

See [AI Providers](/docs/configuration/providers).

## Cloud AI Requests

ANAS CLI includes a cloud OpenAI integration.

The current cloud OpenAI endpoint uses `gpt-4o` and supports:

- Standard AI responses
- Streaming responses
- Tool-call responses
- Token usage information when available

Cloud OpenAI requests are limited to **30 requests per minute per authenticated user**.

If the limit is exceeded, the backend returns HTTP `429` with a `Retry-After` header.

Rate limiting does not guarantee a maximum API bill.

See [ANAS Cloud](/docs/guides/anas-cloud) and [Security](/docs/guides/security).

## `banner`

Display the welcome banner.

```bash
npm run dev -- banner
```

## `hello`

Print a greeting.

```bash
npm run dev -- hello
```

## Help and Version

Display available commands and options:

```bash
npm run dev -- --help
```

Display the installed CLI version:

```bash
npm run dev -- --version
```

The reported version depends on the installed ANAS CLI release.

## Slash Commands

These commands are available inside an interactive chat session:

| Command       | Description                   |
| ------------- | ----------------------------- |
| `/help`       | Show available chat commands. |
| `/exit`       | Exit the chat session.        |
| `/new`        | Start a new conversation.     |
| `/history`    | View conversation history.    |
| `/resume`     | Resume a conversation.        |
| `/mode ask`   | Switch to Ask mode.           |
| `/mode agent` | Switch to Agent mode.         |
| `/mode plan`  | Switch to Plan mode.          |

Unknown slash commands display the available command help.
